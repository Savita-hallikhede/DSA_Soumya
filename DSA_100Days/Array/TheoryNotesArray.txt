📘 ARRAYS — COMPLETE INTERVIEW NOTES
1. What is an Array?
An array is a data structure used to store multiple elements of the same data type in a single variable.
Example:
10  20  30  40  50
Each value is called an element.

2. Why do we use an Array?
If we have many values of the same type, instead of creating separate variables, we can store them together.
Without array:
int a = 10;
int b = 20;
int c = 30;
With array:
int[] arr = {10, 20, 30};
4. What is an Index?
An index represents the position of an element in an array.
Important:
Array indexing starts from 0.
Element:  10   20   30   40
Index:     0    1    2    3
5. Why does Array indexing start from 0?
This is a common interview question.
The index represents an offset from the starting memory location.
The first element is at an offset of 0, so its index is 0.
For interviews, you can simply say:
Array indexing starts from 0 because the index represents the offset from the beginning of the array.
6. What is the size of an Array?
The size means the number of elements/positions the array can contain.
Example:
[10] [20] [30] [40] [50]
Size = 5
In C#:
arr.Length
gives the size.
7. Is an Array fixed-size?
Yes.
A normal C# array has a fixed length once it is created.
Example:
int[] arr = new int[5];
It has 5 positions.
You cannot make that same array become 6 positions.
Important distinction:
Array size is fixed, but its values can be changed.
8. Can we change an Array element?
Yes.
Suppose:
10  20  30  40
You can replace 30 with 100.
10  20 100  40
So:
Array is fixed in size, but elements can be modified.



9. Can we insert an element into an Array?
Yes, as an operation — but not by increasing the existing array's size.
Suppose:
10  20  30  40
To insert 25:
10  20  25  30  40
Because the original array cannot grow, normally we need to:
1.	Create a larger array. 
2.	Copy the existing elements. 
3.	Shift elements. 
4.	Insert the new element.
10. Can we delete an element from an Array?
Yes, logically.
But the array's actual size does not decrease.
Example:
10  20  30  40  50
Delete 30:
10  20  40  50  _
The array still has 5 positions.
Usually, elements are shifted left.
12. What is Array Traversal?
Traversal means visiting each element of an array one by one.
Example:
10 → 20 → 30 → 40 → 50
When solving DSA problems, traversal is extremely important.
Commonly done using:
•	for 
•	foreach and while
13. What operations can be performed on Arrays?
This is a very important interview question.
Common array operations:
1. Traversal
Visit every element.
2. Insertion
Add an element.
3. Deletion
Remove an element logically.
4. Searching
Find an element.
5. Updating
Change an existing element.
6. Sorting
Arrange elements in order.
Example:
Before:
40 10 30 20

After sorting:
10 20 30 40
14. What are the advantages of Arrays?
Advantages:
•	Simple to use. 
•	Fast access using index. 
•	Stores elements of the same type. 
•	Memory-efficient for fixed-size data. 
•	Easy to traverse. 
•	Good for storing a known number of elements. 
________________________________________
15. What are the disadvantages of Arrays?
Disadvantages:
•	Fixed size. 
•	Insertion can be costly. 
•	Deletion can be costly because of shifting. 
•	Can waste space if the allocated size is much larger than needed. 
•	Cannot easily grow or shrink.

16. Why is Array access fast?
This is a very common interview question.
If you know the index:
arr[3]
the system can directly calculate where that element is located.
Therefore, accessing an element by index is generally:
O(1) — Constant Time
You don't need to check every element.
Example:
10 20 30 40 50
         ↑
       arr[3]
It directly accesses 40.

17. What is the time complexity of Array operations?
Very important for interviews:
Operation	Time Complexity
Access by index	O(1)
Update by index	O(1)
Linear Search	O(n)
Traversal	O(n)
Insertion at beginning	O(n)
Insertion at middle	O(n)
Deletion at beginning	O(n)
Deletion at middle	O(n)
Why insertion/deletion can be O(n)?
Because elements may need to be shifted.

🟢 O(1) — Constant Time
O(1) means the amount of work stays almost the same, no matter how big the input is.
Example:
int[] arr = { 10, 20, 30, 40, 50 };

Console.WriteLine(arr[3]);
You directly ask for index 3.
arr[3] → 40
Whether the array has:
5 elements
100 elements
1,000,000 elements
you still directly access arr[3].
So:
Array access by index = O(1) ✅
Think:
"I know the location → go directly there."
________________________________________
🔵 O(n) — Linear Time
O(n) means the amount of work increases as the number of elements increases.
Example: searching for 40.
10  20  30  40  50
You may need to check:
10 → ❌
20 → ❌
30 → ❌
40 → ✅
If there are 5 elements, you may check up to 5.
If there are 100 elements, you may check up to 100.
If there are 1,000 elements, you may check up to 1,000.
So:
Linear search = O(n) ✅
Think:
"I don't know where it is → I may have to check everyone."

18. Array vs List
Another very common C# interview question.
Array	List
Fixed size	Dynamic size
int[]	List<int>
Uses .Length	Uses .Count
Cannot directly Add()	Can use Add()
Less flexible	More flexible
Good for fixed-size data	Good when size changes

	
19. What is a One-Dimensional Array?
A one-dimensional array stores elements in a single sequence.
Example:
10 20 30 40 50
C#:
int[] arr;
This is the most common type you'll use in basic DSA.


20. What is a Two-Dimensional Array?
A 2D array stores data in rows and columns.
Think of it like a table:
10 20 30
40 50 60
70 80 90
C#:
int[,] matrix;
It is commonly used for:
•	Matrices 
•	Tables 
•	Grid problems 
•	Game boards
21. What is a Multidimensional Array?
An array can have more than two dimensions.
For example:
1D → int[]
2D → int[,]
3D → int[,,]

22. What is a Jagged Array in C#?
This is a C# interview-specific question.
A jagged array is an array of arrays, where each inner array can have a different size.
Example:
Row 1 → 10 20
Row 2 → 30 40 50
Row 3 → 60
Unlike a normal rectangular 2D array, the rows don't need to have the same length.



24. What happens if you access an invalid index?
Suppose:
int[] arr = {10, 20, 30};
Valid indexes:
0, 1, 2
If you try:
arr[3]
C# throws an:
IndexOutOfRangeException
because index 3 doesn't exist.
